## MODIFIED Requirements

### Requirement: 진단 및 재시도
시스템은 저장소 조회 또는 통합 결과 생성에 실패하면 문제 범위, 원인과 사용자가
수행할 다음 행동을 표시해야 한다(SHALL). 사용자가 입력을 고친 뒤 현재 화면에서
재시도할 수 있어야 한다(SHALL).

#### Scenario: 지원 범위를 벗어난 커밋
- **WHEN** 선택 커밋이 현재 비교 범위에 포함되지 않거나 적용 순서를 결정할 수 없다
- **THEN** 시스템은 문제가 된 커밋과 지원되지 않는 범위를 표시한다
- **AND** 비교 범위 또는 커밋 선택을 변경하는 행동을 안내한다

#### Scenario: 변경 적용 실패
- **WHEN** 선택한 변경을 통합하는 중 Git 오류가 발생한다
- **THEN** 시스템은 통합 결과를 완료 상태로 표시하지 않는다
- **AND** 실패한 작업 범위, 확인 가능한 원인과 저장소 상태를 확인한 뒤 재시도하는 행동을 안내한다
- **AND** 현재 저장소, 비교 범위와 커밋 선택을 유지한다

#### Scenario: 저장소 잠금, 접근 권한 또는 저장 장치 실패
- **WHEN** 통합 결과 생성이 저장소 잠금, 접근 권한 또는 저장 장치 문제로 실패한다
- **THEN** 시스템은 확인된 문제 범위를 구분해 표시한다
- **AND** 잠금을 해제하거나 접근 권한과 저장 공간을 확인한 뒤 다시 실행하는 행동을 안내한다
- **AND** Git 명령, 임시 경로와 원문 오류는 화면에 표시하지 않는다

#### Scenario: 화면 경계 호출 실패
- **WHEN** 데스크톱 화면과 로컬 작업 기능 사이의 요청이 잘못되거나 처리 중 연결이 끊긴다
- **THEN** 시스템은 현재 결과를 새 결과로 교체하지 않는다
- **AND** 요청한 작업, 실패 원인과 다시 실행할 행동을 표시한다

### Requirement: 읽기 전용 파일 검토
시스템은 수정 또는 삭제된 텍스트 파일의 비교 기준 내용을 왼쪽에, 통합 결과
내용을 오른쪽에 두는 읽기 전용 좌우 diff를 제공해야 한다(SHALL). 추가된
텍스트 파일은 전체 내용을 한 번만 읽기 전용으로 표시해야 한다(SHALL).

#### Scenario: 수정 파일 비교
- **WHEN** 사용자가 수정 상태의 텍스트 파일을 선택한다
- **THEN** 시스템은 왼쪽에 비교 기준 파일, 오른쪽에 통합 결과 파일을 표시한다
- **AND** 파일 경로, 줄 번호와 대응하는 변경 구간을 함께 표시한다

#### Scenario: 추가 파일 검토
- **WHEN** 사용자가 추가 상태의 텍스트 파일을 선택한다
- **THEN** 시스템은 기준 revision이 없음을 표시한다
- **AND** 기준 화면 없이 통합 결과 파일 전체 내용을 한 번 표시한다
- **AND** 표시된 모든 줄을 추가된 내용으로 구분한다

#### Scenario: 삭제 파일 비교
- **WHEN** 사용자가 삭제 상태의 텍스트 파일을 선택한다
- **THEN** 시스템은 왼쪽에 비교 기준 파일 내용을 표시한다
- **AND** 오른쪽을 빈 최종 상태로 표시한다

#### Scenario: 파일 내용 편집 시도
- **WHEN** 사용자가 파일 검토 화면의 내용을 편집하려 한다
- **THEN** 시스템은 파일 내용을 변경하지 않고 읽기 전용 상태를 유지한다

#### Scenario: 보조 기술로 파일 검토 열기
- **WHEN** 사용자가 키보드 또는 보조 기술로 파일 검토 영역을 연다
- **THEN** 시스템은 파일 상태와 표시 중인 내용을 구분하는 이름 및 접근 가능한 변경 내용을 제공한다

## ADDED Requirements

### Requirement: 파일 검토 자원 정리
시스템은 diff 편집기 준비가 실패하거나 표시 대상이 바뀌면 해당 시도에서 만든
편집기, model과 장식을 모두 해제해야 한다(MUST).

#### Scenario: 편집기 model 연결 실패
- **WHEN** 파일 검토 편집기를 만든 뒤 model 연결 또는 장식 준비가 실패한다
- **THEN** 시스템은 해당 시도에서 만든 편집기와 model을 모두 해제한다
- **AND** 오류 경계에서 다시 시도할 수 있는 상태를 제공한다

#### Scenario: 파일 검토 대상 변경
- **WHEN** 사용자가 다른 파일을 선택하거나 파일 검토 화면을 닫는다
- **THEN** 시스템은 이전 파일에 사용한 편집기, model과 장식을 해제한다
