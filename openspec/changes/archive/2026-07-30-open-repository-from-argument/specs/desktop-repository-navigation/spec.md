## MODIFIED Requirements

### Requirement: 로컬 Git 저장소 열기
시스템은 운영체제 폴더 선택 창을 통해 로컬 Git 저장소를 열고 현재 열린 저장소를 명확히 표시해야 한다(SHALL). 시스템은 앱을 시작할 때 명령행 인자로 받은 경로를 열 대상으로 사용해야 한다(SHALL).

#### Scenario: 유효한 저장소 선택
- **WHEN** 사용자가 폴더 선택 창에서 유효한 로컬 Git 저장소를 선택한다
- **THEN** 시스템은 저장소의 정규화된 경로와 현재 브랜치를 표시한다
- **AND** 비교 범위 선택 화면을 사용할 수 있게 한다

#### Scenario: 폴더 선택 취소
- **WHEN** 사용자가 폴더 선택 창을 취소한다
- **THEN** 시스템은 현재 열려 있는 저장소와 화면 상태를 유지한다

#### Scenario: Git 저장소가 아닌 폴더 선택
- **WHEN** 사용자가 Git 저장소가 아닌 폴더를 선택한다
- **THEN** 시스템은 문제가 발생한 경로와 저장소를 열 수 없는 원인을 표시한다
- **AND** 다른 폴더를 선택하는 행동을 안내한다
- **AND** 이전에 정상적으로 연 저장소가 있으면 그 상태를 유지한다

#### Scenario: Git 실행 파일을 사용할 수 없음
- **WHEN** 시스템이 로컬 Git 실행 파일을 찾거나 실행할 수 없다
- **THEN** 시스템은 Git 실행 환경이 필요함을 표시한다
- **AND** Git 설치와 실행 경로를 확인하는 행동을 안내한다

#### Scenario: 명령행 인자로 받은 저장소로 시작
- **WHEN** 사용자가 유효한 로컬 Git 저장소 경로를 명령행 인자로 주고 앱을 시작한다
- **THEN** 시스템은 폴더 선택 없이 그 저장소를 열고 정규화된 경로와 현재 브랜치를 표시한다
- **AND** 비교 범위 선택 화면을 사용할 수 있게 한다

#### Scenario: 명령행 인자가 없음
- **WHEN** 사용자가 저장소 경로 없이 앱을 시작한다
- **THEN** 시스템은 저장소를 열지 않은 상태로 시작하고 저장소를 열 수 있는 행동을 제공한다
- **AND** 오류를 표시하지 않는다

#### Scenario: 명령행 인자가 유효한 저장소가 아님
- **WHEN** 사용자가 존재하지 않는 경로나 Git 저장소가 아닌 경로를 명령행 인자로 주고 앱을 시작한다
- **THEN** 시스템은 문제가 발생한 경로와 저장소를 열 수 없는 원인을 표시한다
- **AND** 다른 저장소를 열 수 있는 행동을 제공한다
