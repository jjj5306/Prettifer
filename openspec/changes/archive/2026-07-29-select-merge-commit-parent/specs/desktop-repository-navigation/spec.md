## MODIFIED Requirements

### Requirement: 합성 선택과 현재 탐색 구분
시스템은 통합 결과에 포함할 커밋의 체크 상태와 현재 자세히 살펴보는 커밋의 탐색 상태를 서로 다른 표시로 유지해야 한다(SHALL). merge commit은 기준 부모를 정하는 흐름과 함께 체크할 수 있어야 한다(SHALL).

#### Scenario: 비연속 커밋 선택
- **WHEN** 사용자가 선형 흐름에서 서로 떨어진 합성 가능 커밋의 체크 상자를 선택한다
- **THEN** 시스템은 선택한 모든 커밋의 체크 상태와 선택 개수를 표시한다
- **AND** 사이에 있는 선택하지 않은 커밋은 체크되지 않은 상태로 유지한다

#### Scenario: 선택하지 않은 커밋 탐색
- **WHEN** 사용자가 합성 대상으로 체크하지 않은 커밋 행을 연다
- **THEN** 시스템은 기존 체크 상태를 유지한다
- **AND** 현재 살펴보는 커밋만 별도의 탐색 상태로 표시한다

#### Scenario: 모든 선택 해제
- **WHEN** 사용자가 모든 커밋의 체크를 해제한다
- **THEN** 시스템은 선택 개수를 0으로 표시한다
- **AND** 통합 결과를 만들려면 하나 이상의 커밋을 선택해야 함을 안내한다

#### Scenario: merge commit 체크
- **WHEN** 사용자가 부모가 둘 이상인 커밋의 체크 상자를 선택한다
- **THEN** 시스템은 그 커밋을 선택 상태로 표시하고 선택 개수에 포함한다
- **AND** 기준 부모를 고르는 수단을 그 커밋에 표시한다

#### Scenario: 기준 부모 선택
- **WHEN** 사용자가 체크한 merge commit의 기준 부모를 고른다
- **THEN** 시스템은 고른 기준 부모를 그 커밋에 표시한다
- **AND** 다른 커밋의 체크 상태와 선택 개수는 바뀌지 않는다

#### Scenario: 기준 부모를 정하지 않은 상태
- **WHEN** 체크한 merge commit의 기준 부모가 아직 정해지지 않았다
- **THEN** 시스템은 기준 부모가 필요함을 그 커밋에 표시한다
- **AND** 통합 결과를 만드는 행동을 실행할 수 없는 상태로 표시한다

#### Scenario: merge commit 체크 해제
- **WHEN** 사용자가 기준 부모를 정한 merge commit의 체크를 해제한다
- **THEN** 시스템은 그 커밋을 선택 목록에서 제외한다
- **AND** 남은 선택으로 통합 결과를 만들 수 있는 상태를 다시 판단한다
