## ADDED Requirements

### Requirement: 이름 변경 파일의 좌우 통합 diff
시스템은 통합 결과에서 이름이 변경된 파일의 이전 경로와 현재 경로를 하나의
좌우 비교로 제공해야 한다(SHALL). 파일 내용도 변경되었으면 이전 내용과 최종
내용을 같은 비교에서 제공해야 한다(SHALL).

#### Scenario: 경로와 내용이 함께 변경됨
- **WHEN** 선택한 커밋으로 파일의 경로와 내용이 모두 변경된다
- **THEN** 시스템은 왼쪽에 이전 경로와 이전 내용을 표시한다
- **AND** 오른쪽에 현재 경로와 최종 내용을 표시한다

#### Scenario: 경로만 변경됨
- **WHEN** 선택한 커밋으로 파일 내용은 유지되고 경로만 변경된다
- **THEN** 시스템은 이전 경로와 현재 경로를 하나의 이름 변경으로 표시한다
- **AND** 해당 파일을 삭제된 파일과 추가된 파일로 나누어 표시하지 않는다
