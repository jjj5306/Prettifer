## Why

Prettifer는 현재 두 브랜치의 공통 조상부터 이어지는 선형 커밋 흐름과 선택한
커밋의 통합 결과를 제공한다. 저장소의 분기와 병합을 한눈에 탐색하고, 이력이
일부만 있는 저장소와 루트 이력 및 이름 변경 파일도 정확히 검토하려면 남은
동작과 검증 기준이 필요하다.

## What Changes

- 저장소에서 확인할 수 있는 전체 커밋 흐름을 분기와 병합 관계가 보이는
  그래프로 제공한다.
- 그래프의 커밋에 연결된 브랜치와 태그를 표시한다.
- 저장소 이력이 일부만 있으면 확인 가능한 범위와 원인을 안내한다.
- 이전 상태가 없는 루트 이력은 빈 저장소 상태를 비교 기준으로 사용한다.
- 이름이 변경된 파일은 이전 경로와 현재 경로 및 내용 변경을 좌우로 표시한다.
- 원본 기능 시나리오를 자동 검증 항목에 연결하고, 1초를 넘는 계산의 처리
  범위와 취소 동작을 실제 흐름에서 검증한다.

## Capabilities

### New Capabilities

- `repository-history`: 전체 커밋 흐름, 브랜치와 태그 및 불완전한 이력 안내
- `commit-composition`: 루트 이력의 비교 기준과 장시간 계산 상태
- `file-change-exploration`: 이름 변경 파일의 좌우 비교

### Modified Capabilities

없음.

## Impact

- 전체 저장소 이력을 읽고 그래프로 표현하는 동작이 영향을 받는다.
- 루트 이력의 최종 결과 계산과 이름 변경 파일 표현이 영향을 받는다.
- 원본 기능 시나리오와 자동 검증 항목의 연결이 영향을 받는다.
