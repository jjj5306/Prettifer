## Why

Electron 전체 흐름 검증에 필요한 세 가지 주입점(저장소 폴더 선택, Git 실행 경로, 계산 지연)이
지금은 운영 main 진입점 안에 있다. 배포되는 패키지가 `PRETTIFER_E2E_*` 환경 변수를 읽는
코드를 포함한다는 뜻이다.

실행 코드에 테스트 전용 분기가 남아 있으면 두 가지가 나빠진다. 배포물이 테스트용 입력에
반응할 수 있고, 운영 진입점을 읽는 사람이 어디까지가 제품 동작인지 구분할 수 없다.

## What Changes

사용자가 관찰하는 제품 동작은 바뀌지 않는다. 조립 지점과 검증 대상이 갈라진다.

- 앱 수명주기와 보안 설정을 한 곳에 모으고, 세 주입점을 매개변수로 받는다.
- 운영 진입점은 실제 폴더 대화상자만 넘긴다. 환경 변수를 읽지 않는다.
- 테스트 전용 진입점이 환경 변수에서 주입점을 만들어 같은 조립 지점에 넘긴다.
- 두 진입점을 별도 번들로 빌드하고, 배포 패키지에서는 테스트 번들을 제거한다.
- Playwright 전체 흐름은 테스트 진입점으로, 패키지 smoke는 운영 진입점으로 실행한다.

## Capabilities

### New Capabilities

없음.

### Modified Capabilities

없음. 운영 동작과 화면이 그대로이므로 메인 스펙은 변경하지 않는다. 검증 기준은 배포 번들에
테스트 코드가 없다는 것과 수명주기 계약 테스트다.

## Impact

- `src/desktop/main/`: 조립 지점 분리, 운영·테스트 진입점 2개
- `build/webpack.main.config.cjs`: 진입점 2개 빌드
- `forge.config.cjs`: 패키지에서 테스트 번들 제거
- `test/e2e/`: 흐름 테스트는 테스트 진입점, smoke는 운영 진입점
- 렌더러, preload, 공유 계약과 Git·합성 코어는 변경하지 않는다
