## 3. 순수 핵심

- [x] 3.1 경로 목록과 통합 결과를 합쳐 트리 항목의 상태를 정한다

- [x] 3.3 변경 파일의 상위 폴더만 펼친 초기 접힘 집합을 만든다

## 4. 상태와 조회 시점

- [x] 4.1 경로 목록 상태를 비교 범위 단위로 보관한다
