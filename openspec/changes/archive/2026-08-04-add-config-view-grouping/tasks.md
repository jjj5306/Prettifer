## 1. 순수 핵심

- [x] 1.1 경로 prefix를 저장소 상대 경로 정규형으로 맞춘다
- [x] 1.2 규칙 하나의 유효성을 판정하고 무효 원인을 값으로 돌려준다
- [x] 1.3 규칙 목록에서 중복 prefix, 중복 그룹 이름과 상한 초과를 판정한다
- [x] 1.4 경로가 prefix에 세그먼트 경계로 일치하는지 판정한다
- [x] 1.5 파일 경로에 적용할 규칙을 가장 긴 prefix로 고른다
- [x] 1.6 변경 파일 목록과 규칙 목록으로 그룹 목록과 미분류 그룹을 만든다
- [x] 1.7 그룹 파일 수의 합이 변경 파일 전체 수와 같음을 테스트로 고정한다
- [x] 1.8 표시 순서를 바꿔도 파일이 속한 그룹이 같음을 테스트로 고정한다
