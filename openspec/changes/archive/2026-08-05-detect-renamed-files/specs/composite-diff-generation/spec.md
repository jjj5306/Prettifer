## ADDED Requirements

### Requirement: 이름 변경 파일 식별
시스템은 선택 커밋이 파일의 경로를 바꾼 것을 하나의 이름 변경으로 판정해야 한다(SHALL). 이름
변경으로 판정한 파일은 하나의 변경으로 제공하고, 비교 기준의 경로와 결과의 경로를 함께 제공해야
한다(MUST). 판정에 사용한 내용 일치 비율도 함께 제공해야 한다(MUST). 판정 기준은 Git 설정이 아니라
계산이 정해야 한다(MUST).

#### Scenario: 내용을 그대로 옮긴 파일
- **WHEN** 선택 커밋이 파일을 내용 변경 없이 다른 경로로 옮긴다
- **THEN** 최종 결과는 그 파일을 하나의 이름 변경으로 제공한다
- **AND** 비교 기준의 경로와 결과의 경로를 함께 제공한다
- **AND** 추가와 삭제로 나누어 제공하지 않는다

#### Scenario: 옮기면서 내용도 바꾼 파일
- **WHEN** 선택 커밋이 파일을 다른 경로로 옮기면서 내용도 일부 바꾼다
- **THEN** 최종 결과는 그 파일을 하나의 이름 변경으로 제공한다
- **AND** 통합 diff는 경로 변경과 내용 변경을 그 파일의 하나의 변경으로 보여준다
- **AND** 일치 비율은 100보다 작다

#### Scenario: 이름 변경으로 판정할 수 없는 파일
- **WHEN** 선택 커밋이 파일을 옮기면서 내용을 판정 기준보다 많이 바꾼다
- **THEN** 최종 결과는 이전 경로를 삭제로, 새 경로를 추가로 제공한다
- **AND** 두 경로 모두 결과에서 빠지지 않는다

#### Scenario: 판정 후보가 상한을 넘음
- **WHEN** 한 계산의 이름 변경 판정 후보가 계산이 정한 상한을 넘는다
- **THEN** 시스템은 판정하지 못한 파일을 추가와 삭제로 제공한다
- **AND** 어떤 경로도 결과에서 빠지지 않는다

#### Scenario: 사용자 Git 설정과 무관한 판정
- **WHEN** 사용자 Git 설정이 이름 변경 판정을 끄거나 다른 비율로 정해 두었다
- **THEN** 시스템은 계산이 정한 기준으로 판정한 같은 결과를 제공한다

## MODIFIED Requirements

### Requirement: 선택 커밋만 반영된 통합 결과
시스템은 비교 기준에 선택한 커밋의 변경만 반영한 최종 파일 상태와 하나의 통합 diff를 제공해야 한다(SHALL). 미선택 커밋만이 만든 변경은 최종 파일 상태와 통합 diff에 포함하지 않아야 한다(MUST NOT). 각 파일의 상태는 추가, 수정, 삭제와 이름 변경으로 구분해야 한다(MUST).

#### Scenario: 미선택 변경 제외
- **WHEN** 로그인 검증, 내부 리팩터링, 세션 저장과 인증 문서 변경 커밋 중 로그인 검증과 세션 저장 커밋만 선택한다
- **THEN** 최종 파일 상태에는 선택한 로그인 검증과 세션 저장 변경이 포함된다
- **AND** 내부 리팩터링과 인증 문서 변경은 포함되지 않는다

#### Scenario: 파일 추가 수정 삭제 표현
- **WHEN** 선택한 커밋들이 텍스트 파일을 추가하고 기존 파일을 수정하며 다른 파일을 삭제한다
- **THEN** 최종 결과는 비교 기준에 대한 각 파일의 최종 추가, 수정과 삭제 상태를 보여준다
- **AND** 통합 diff는 각 파일의 최종 변경 내용을 보여준다

### Requirement: 동일 입력의 결과 일관성
시스템은 저장소 상태, 비교 기준과 선택 커밋 집합이 같으면 운영체제의 작업
트리 텍스트 변환 설정과 관계없이 반복 계산에서 동일한 최종 파일 상태와 통합
diff를 제공해야 한다(SHALL). 이를 위해 계산에는 원본 저장소의 파일 내용에 영향을
주는 Git 설정을 반영해야 한다(MUST). 파일 상태 판정에 쓰는 설정은 반영하지 않아야 한다(MUST NOT).

#### Scenario: 같은 선택 반복 계산
- **WHEN** 저장소를 변경하지 않고 같은 비교 기준과 커밋을 여러 번 선택해 계산한다
- **THEN** 각 계산의 파일 순서, 최종 파일 내용과 통합 diff가 동일하다

#### Scenario: Windows 작업 트리 줄바꿈 변환
- **WHEN** Windows의 작업 트리 줄바꿈 변환 설정이 임시 파일 내용에 적용될 수 있다
- **THEN** 시스템은 Git index의 최종 객체 내용과 같은 텍스트를 결과로 제공한다
- **AND** 반복 계산의 파일 내용과 통합 diff가 바뀌지 않는다

#### Scenario: 원본 저장소의 내용 설정을 반영한 계산
- **WHEN** 원본 저장소에 파일 내용이나 줄바꿈에 영향을 주는 Git 설정이 있다
- **THEN** 시스템은 계산에 그 설정을 반영한 결과를 제공한다
- **AND** 원본 저장소의 설정은 계산 전과 같다

#### Scenario: 저장소 전용 driver가 필요한 계산
- **WHEN** 계산에 반영한 설정에 저장소 전용 merge 또는 filter driver가 포함된다
- **THEN** 시스템은 선택 커밋이 변경하는 경로만이 아니라 비교 기준의 전체 파일을 준비해 계산한다
- **AND** 그 driver가 다른 파일을 참조해도 같은 결과를 제공한다
