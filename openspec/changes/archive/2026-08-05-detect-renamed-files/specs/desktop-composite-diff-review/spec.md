## ADDED Requirements

### Requirement: 이름 변경 파일 검토
시스템은 이름이 바뀐 파일의 검토 화면에서 비교 기준의 경로와 결과의 경로를 함께 표시해야
한다(MUST). 내용 변경이 있으면 두 경로의 내용을 좌우 diff로 표시해야 한다(MUST). 내용 변경이 없어도
경로가 바뀌었음을 표시해야 한다(MUST).

#### Scenario: 옮기면서 내용도 바꾼 파일 검토
- **WHEN** 사용자가 이름이 바뀌고 내용도 바뀐 파일을 선택한다
- **THEN** 시스템은 이전 경로와 현재 경로를 함께 표시한다
- **AND** 왼쪽에 이전 경로의 비교 기준 내용, 오른쪽에 현재 경로의 결과 내용을 표시한다

#### Scenario: 내용을 그대로 옮긴 파일 검토
- **WHEN** 사용자가 내용 변경 없이 경로만 바뀐 파일을 선택한다
- **THEN** 시스템은 이전 경로와 현재 경로를 함께 표시한다
- **AND** 좌우 내용이 같음을 확인할 수 있게 표시한다

#### Scenario: 이름 변경 판정 기준 확인
- **WHEN** 사용자가 이름이 바뀐 파일을 보고 있다
- **THEN** 시스템은 판정에 사용한 내용 일치 비율을 표시한다

## MODIFIED Requirements

### Requirement: 변경 파일 목록 탐색
시스템은 성공한 통합 결과의 파일을 저장소 상대 경로 순서로 표시하고 추가, 수정, 삭제와 이름 변경 상태를 구분해야 한다(SHALL). 문제 파일은 같은 목록의 원래 경로 위치에서 문제 상태로 구분해야 한다(MUST). 이름이 바뀐 파일은 현재 경로 한 자리에만 표시해야 한다(MUST).

#### Scenario: 여러 변경 파일 확인
- **WHEN** 통합 결과에 추가, 수정 또는 삭제된 파일이 있다
- **THEN** 시스템은 각 파일의 저장소 상대 경로와 변경 상태를 안정적인 경로 순서로 표시한다
- **AND** 첫 번째 파일을 기본 탐색 대상으로 표시한다

#### Scenario: 이름 변경 파일이 포함된 목록
- **WHEN** 통합 결과에 이름이 바뀐 파일이 있다
- **THEN** 시스템은 그 파일을 현재 경로의 자리에 한 번 표시한다
- **AND** 추가, 수정, 삭제와 구분되는 이름 변경 상태로 표시한다
- **AND** 보조 기술에 이전 경로를 함께 알린다

#### Scenario: 키보드로 파일 변경
- **WHEN** 사용자가 키보드로 다른 변경 파일을 선택한다
- **THEN** 시스템은 파일 목록의 현재 위치와 선택 파일을 표시한다
- **AND** 파일 검토 화면을 선택한 파일 내용으로 갱신한다

#### Scenario: 문제 파일이 포함된 목록
- **WHEN** 통합 결과에 문제 파일이 있다
- **THEN** 시스템은 문제 파일을 경로 순서상 원래 위치에 표시한다
- **AND** 추가, 수정, 삭제와 구분되는 문제 상태로 표시한다
- **AND** 보조 기술에 그 파일이 문제 상태임을 알린다
