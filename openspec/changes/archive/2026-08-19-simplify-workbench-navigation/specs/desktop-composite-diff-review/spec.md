## MODIFIED Requirements

### Requirement: 읽기 전용 파일 검토
시스템은 수정 또는 삭제된 텍스트 파일의 비교 기준 내용을 왼쪽에, 통합 결과
내용을 오른쪽에 두는 읽기 전용 좌우 diff를 제공해야 한다(SHALL). 추가된
텍스트 파일은 전체 내용을 한 번만 읽기 전용으로 표시해야 한다(SHALL). 통합 결과가
건드리지 않은 추적 파일은 비교 기준 내용을 하나의 문서로 표시해야 한다(MUST). 검토
화면은 지금 검토 중인 파일의 경로를 화면에 표시해야 한다(MUST). 비교를 표시하는 검토
화면의 제목은 `Differentia Codicis`여야 하며(MUST), 제목에 좌우 또는 인라인 배치를
나타내지 않아야 한다(MUST NOT).

#### Scenario: 수정 파일 비교
- **WHEN** 사용자가 수정 상태의 텍스트 파일을 선택한다
- **THEN** 시스템은 왼쪽에 비교 기준 파일, 오른쪽에 통합 결과 파일을 표시한다
- **AND** 파일 경로, 줄 번호와 대응하는 변경 구간을 함께 표시한다

#### Scenario: 검토 중인 파일 확인
- **WHEN** 사용자가 파일 검토 화면을 보고 있다
- **THEN** 시스템은 검토 중인 파일의 경로를 검토 화면 머리글에 표시한다
- **AND** 검토 대상이 바뀌면 표시된 경로도 함께 바뀐다

#### Scenario: 비교 검토 화면 제목 확인
- **WHEN** 사용자가 수정 또는 삭제된 파일의 비교를 보고 있다
- **THEN** 검토 화면 머리글의 제목이 `Differentia Codicis`로 표시된다
- **AND** 좌우와 인라인 배치는 제목이 아닌 보기 토글로 구분한다

#### Scenario: 추가 파일 검토
- **WHEN** 사용자가 추가 상태의 텍스트 파일을 선택한다
- **THEN** 시스템은 기준 revision이 없음을 표시한다
- **AND** 기준 화면 없이 통합 결과 파일 전체 내용을 한 번 표시한다
- **AND** 표시된 모든 줄을 추가된 내용으로 구분한다

#### Scenario: 삭제 파일 비교
- **WHEN** 사용자가 삭제 상태의 텍스트 파일을 선택한다
- **THEN** 시스템은 왼쪽에 비교 기준 파일 내용을 표시한다
- **AND** 오른쪽을 빈 최종 상태로 표시한다

#### Scenario: 변경되지 않은 파일 검토
- **WHEN** 사용자가 통합 결과가 건드리지 않은 추적 파일을 선택한다
- **THEN** 시스템은 비교 기준 내용을 하나의 문서로 표시한다
- **AND** 그 내용이 선택 결과가 아님을 표시한다
- **AND** 좌우 비교 대상을 표시하지 않는다

#### Scenario: 파일 내용 편집 시도
- **WHEN** 사용자가 파일 검토 화면의 내용을 편집하려 한다
- **THEN** 시스템은 파일 내용을 변경하지 않고 읽기 전용 상태를 유지한다

#### Scenario: 보조 기술로 파일 검토 열기
- **WHEN** 사용자가 키보드 또는 보조 기술로 파일 검토 영역을 연다
- **THEN** 시스템은 파일 상태와 표시 중인 내용을 구분하는 이름 및 접근 가능한 변경 내용을 제공한다
