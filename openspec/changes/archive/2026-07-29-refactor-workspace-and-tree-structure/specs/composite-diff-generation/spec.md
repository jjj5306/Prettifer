## MODIFIED Requirements

### Requirement: 동일 입력의 결과 일관성
시스템은 저장소 상태, 비교 기준과 선택 커밋 집합이 같으면 운영체제의 작업
트리 텍스트 변환 설정과 관계없이 반복 계산에서 동일한 최종 파일 상태와 통합
diff를 제공해야 한다(SHALL). 이를 위해 계산에는 원본 저장소의 파일 내용에 영향을
주는 Git 설정을 반영해야 한다(MUST).

#### Scenario: 원본 저장소의 내용 설정을 반영한 계산
- **WHEN** 원본 저장소에 파일 내용이나 줄바꿈에 영향을 주는 Git 설정이 있다
- **THEN** 시스템은 계산에 그 설정을 반영한 결과를 제공한다
- **AND** 원본 저장소의 설정은 계산 전과 같다

#### Scenario: 저장소 전용 driver가 필요한 계산
- **WHEN** 계산에 반영한 설정에 저장소 전용 merge 또는 filter driver가 포함된다
- **THEN** 시스템은 선택 커밋이 변경하는 경로만이 아니라 비교 기준의 전체 파일을 준비해 계산한다
- **AND** 그 driver가 다른 파일을 참조해도 같은 결과를 제공한다
