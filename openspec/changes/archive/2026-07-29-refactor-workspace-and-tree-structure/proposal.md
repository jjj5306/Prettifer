## Why

임시 작업 공간 준비와 변경 파일 트리 구성 코드에 다음 사람이 읽고 고치기 어려운
구조가 4건 남아 있다. 지금 동작은 정확하고 테스트로 보호되지만, 이름과 매개변수가
실제 판단을 감추고 있어 이후 변경에서 잘못된 가정이 들어가기 쉽다. 부분 결과
계산(#16)까지 얹힌 상태라 합성 계산 경로가 앞으로 더 자주 수정되므로, 그 전에
정리한다.

## What Changes

사용자가 관찰하는 동작은 바뀌지 않는다. 코드 구조만 바꾼다.

- 설정을 적용하면서 불리언 판단을 함께 돌려주던 메서드를, 적용 결과를 기술하는 값과
  그 값을 읽는 이름 있는 질의로 나눈다.
- 불리언 플래그로 두 갈래 준비 흐름을 담던 메서드를, 전체 작업 트리 준비와 선택 경로
  준비라는 두 개의 이름 있는 동작으로 나눈다.
- 문자열 조각을 이어 만들던 Git 설정 탐색 패턴을, 대상 설정 키 목록 자료에서
  생성하고 그 목록을 테스트로 고정한다.
- 위 구조가 유지해야 하는 계산 규칙을 메인 스펙의 요구사항으로 기록한다.
- 디렉터리를 배열과 맵에 손으로 함께 넣어야 했던 트리 구성 자료 구조를, 삽입 순서를
  유지하는 단일 맵으로 바꿔 두 구조를 맞춰야 하는 불변식을 없앤다.

## Capabilities

### New Capabilities

없음.

### Modified Capabilities

- `composite-diff-generation`: `동일 입력의 결과 일관성`에 이미 구현되어 있으나 이 capability의
  요구사항으로 기록되지 않았던 내용을 추가한다. 원본 저장소의 내용 관련 Git 설정을 계산에
  반영한다는 규칙과, 저장소 전용 driver가 포함되면 선택 경로가 아니라 전체 파일을 준비한다는
  규칙이다. 동작 변경이 아니라 이번 리팩터링이 유지해야 하는 불변식을 검증 가능한 형태로
  남기는 문서 정합성 보완이다.

그 밖의 사용자가 관찰하는 동작은 바뀌지 않으므로 다른 메인 스펙과 사용자 문서는 변경하지
않는다. 기존 요구사항의 회귀는 현재 테스트가 보호한다.

## Impact

- `src/composition/composition-workspace.ts`: 설정 적용 결과 값, 준비 흐름 분리,
  설정 키 목록과 패턴 생성
- `src/desktop/renderer/files/file-tree.ts`: 트리 구성 자료 구조
- `test/unit/composition-workspace.test.ts`: 설정 키 목록 검증 추가
- `test/desktop/renderer/files/file-tree.test.ts`: 디렉터리 중복 제거 검증 추가
- 외부 계약(`src/desktop/shared`), main↔renderer 경계와 Git 명령 사용 방식은 변경
  없음
