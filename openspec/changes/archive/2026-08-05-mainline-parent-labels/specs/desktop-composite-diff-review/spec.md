## MODIFIED Requirements

### Requirement: 통합 결과 범위 표시
시스템은 완성된 통합 결과에 실제 비교 기준 커밋, 포함된 커밋 수, 적용 순서와 작업 트리 보존 상태를 표시해야 한다(SHALL). 포함된 merge commit에는 계산에 사용한 기준 부모를 함께 표시해야 한다(SHALL). 그 기준 부모는 순서 번호가 아니라 병합받은 쪽인지 병합해 들여온 쪽인지로 표시해야 한다(MUST).

#### Scenario: 성공 결과 확인
- **WHEN** 선택 커밋의 통합 결과 생성이 성공한다
- **THEN** 시스템은 실제 비교 기준 커밋과 적용된 커밋을 오래된 순서부터 표시한다
- **AND** 화면의 선택 범위와 결과의 포함 범위가 일치함을 표시한다
- **AND** 현재 브랜치와 작업 중인 파일 상태가 변경되지 않았음을 표시한다

#### Scenario: 변경 파일이 없는 결과
- **WHEN** 선택 변경을 반영한 최종 상태가 비교 기준과 같아 변경 파일이 없다
- **THEN** 시스템은 계산이 성공했고 최종 변경 파일이 없음을 표시한다
- **AND** 이전 파일 선택과 diff를 제거한다

#### Scenario: merge commit이 포함된 결과 확인
- **WHEN** 기준 부모를 정한 merge commit이 포함된 통합 결과 생성이 성공한다
- **THEN** 시스템은 그 커밋에 사용한 기준 부모를 결과 범위와 함께 표시한다
- **AND** 병합받은 쪽인지 병합해 들여온 쪽인지로 표시한다
- **AND** 부모의 순서 번호로 표시하지 않는다
