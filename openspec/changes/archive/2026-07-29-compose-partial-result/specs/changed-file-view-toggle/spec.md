## MODIFIED Requirements

### Requirement: 동일한 파일 상태 표현
시스템은 두 보기에서 동일한 파일 집합, 저장소 상대 경로와 추가, 수정 또는
삭제 상태를 제공해야 한다(MUST). 문제 파일의 문제 상태도 두 보기에서 동일하게
제공해야 한다(MUST).

#### Scenario: 두 보기의 파일 집합
- **WHEN** 사용자가 같은 통합 결과에서 Tree View와 List View를 차례로 확인한다
- **THEN** 두 보기에 표시된 파일의 저장소 상대 경로 집합이 동일하다
- **THEN** 각 파일의 상태가 두 보기에서 동일하다

#### Scenario: 긴 경로 표시
- **WHEN** 변경 파일의 저장소 상대 경로가 패널 너비보다 길다
- **THEN** 행은 다른 작업 영역의 너비를 밀어내지 않는다
- **THEN** 사용자는 보이는 이름 또는 접근 가능한 이름으로 전체 경로를 확인할 수 있다

#### Scenario: 두 보기의 문제 파일
- **WHEN** 문제 파일이 있는 통합 결과에서 사용자가 두 보기를 차례로 확인한다
- **THEN** 두 보기 모두 그 파일을 문제 상태로 표시한다
- **THEN** 문제 파일도 경로 계층과 전체 경로 목록에서 같은 위치에 나타난다
