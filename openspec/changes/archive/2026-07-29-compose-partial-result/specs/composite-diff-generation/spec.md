## MODIFIED Requirements

### Requirement: Git 적용 오류 구분
시스템은 선택 커밋을 적용할 때 실제 파일 충돌과 그 밖의 Git 실행 실패를
구분해야 한다(MUST). 사용자가 취할 다음 행동은 확인된 실패 종류와 일치해야
한다(MUST). 파일 충돌은 계산 전체를 중단시키지 않고 해당 파일만 문제로 기록해야
한다(MUST).

#### Scenario: 병합되지 않은 파일이 있는 일반 충돌
- **WHEN** 선택 커밋 적용이 일반 충돌 종료 코드 1로 실패하고 임시 index에 병합되지 않은 파일이 있다
- **THEN** 시스템은 병합되지 않은 파일을 문제 파일로 기록한다
- **AND** 그 파일을 커밋 적용 직전 상태로 되돌린다
- **AND** 같은 커밋의 나머지 변경은 결과에 유지한다
- **AND** 남은 선택 커밋을 계속 적용한다

#### Scenario: 파일 충돌이 아닌 Git 실행 실패
- **WHEN** 선택 커밋 적용이 일반 충돌 종료 코드 외의 상태나 파일 잠금, 권한 또는 저장 장치 문제로 실패한다
- **THEN** 시스템은 해당 실패를 커밋 충돌로 표시하지 않는다
- **AND** 원래 Git 실패 범위에 맞는 진단과 재시도 행동을 제공한다

## ADDED Requirements

### Requirement: 계산 가능한 파일의 부분 결과
시스템은 일부 파일을 계산할 수 없어도 계산 가능한 파일의 결과를 제공해야
한다(SHALL). 결과는 완전한 결과와 부분 결과를 구분해 제공해야 한다(MUST).

#### Scenario: 일부 파일만 충돌
- **WHEN** 선택 커밋을 적용하는 과정에서 한 파일만 충돌하고 나머지는 적용된다
- **THEN** 시스템은 충돌하지 않은 파일의 최종 상태와 통합 diff를 제공한다
- **AND** 결과를 부분 결과로 표시한다
- **AND** 충돌한 파일을 문제 파일로 함께 제공한다

#### Scenario: 문제가 없는 계산
- **WHEN** 선택 커밋이 모두 문제없이 적용된다
- **THEN** 시스템은 결과를 완전한 결과로 표시한다
- **AND** 문제 파일 목록은 비어 있다

#### Scenario: 계산할 수 있는 파일이 없음
- **WHEN** 선택 커밋을 적용한 결과 계산 가능한 변경 파일이 하나도 남지 않고 문제 파일만 있다
- **THEN** 시스템은 결과를 완료 상태로 제공하지 않는다
- **AND** 문제 범위와 필요한 다음 행동을 알린다

### Requirement: 문제 파일의 원인과 다음 행동
시스템은 각 문제 파일에 문제 원인, 관련 커밋과 사용자가 취할 다음 행동을 제공해야
한다(MUST).

#### Scenario: 선택하지 않은 이전 변경에 의존하는 파일
- **WHEN** 선택 커밋이 선택하지 않은 이전 커밋의 변경에 의존해 한 파일이 충돌한다
- **THEN** 시스템은 그 파일의 원인을 내용 선택이 필요한 충돌로 제공한다
- **AND** 문제를 만든 커밋을 함께 제공한다
- **AND** 필요한 이전 커밋을 함께 선택하도록 안내한다

#### Scenario: 문제 파일에 뒤 커밋이 다시 변경을 시도
- **WHEN** 문제로 기록된 파일을 뒤의 선택 커밋이 다시 변경한다
- **THEN** 시스템은 그 파일을 계속 문제 파일로 유지한다
- **AND** 신뢰할 수 없는 내용을 결과 파일로 제공하지 않는다

#### Scenario: 파일이 없는 상태에서의 충돌
- **WHEN** 적용 직전 상태에 존재하지 않는 파일에서 충돌이 발생한다
- **THEN** 시스템은 그 파일을 결과에서 제외하고 문제 파일로 기록한다
- **AND** 임시 작업 공간에 병합되지 않은 상태를 남기지 않는다
