## MODIFIED Requirements

### Requirement: 선형 커밋 흐름 탐색
시스템은 현재 지원 범위에 맞게 작업 브랜치의 첫 번째 부모를 따라가는 선형
커밋 흐름을 가장 오래된 커밋부터 최신 커밋 순서로 표시해야 한다(SHALL). 추가로 불러온 커밋이
있으면 첫 페이지 상태로 되돌리는 초기화를 제공해야 한다(MUST). 그 초기화는 저장소를 다시 읽지
않아야 한다(MUST NOT).

#### Scenario: 커밋 정보 확인
- **WHEN** 선택한 비교 범위에 커밋이 있다
- **THEN** 시스템은 각 커밋의 짧은 ID, 제목, 작성자와 작성 시각을 가장 오래된 커밋부터 최신 커밋 순서로 표시한다
- **AND** 합성할 수 있는 커밋에 선택 컨트롤을 제공한다

#### Scenario: merge commit 확인
- **WHEN** 선형 흐름에 부모가 둘 이상인 merge commit이 포함된다
- **THEN** 시스템은 해당 커밋이 merge commit임을 표시한다
- **AND** 이번 지원 범위에서 선택할 수 없는 이유를 해당 행에서 안내한다

#### Scenario: 비교 범위에 커밋이 없음
- **WHEN** 공통 조상 이후 작업 브랜치에 표시할 커밋이 없다
- **THEN** 시스템은 현재 비교 범위에 선택할 커밋이 없음을 표시한다
- **AND** 다른 브랜치 범위를 선택하는 행동을 안내한다

#### Scenario: 이전 커밋 추가 로딩
- **WHEN** 현재 페이지보다 오래된 커밋이 있고 사용자가 이전 커밋을 더 불러온다
- **THEN** 시스템은 이미 표시된 커밋, 체크 상태와 현재 키보드 위치를 유지한 채 다음 커밋 페이지를 추가한다

#### Scenario: 불러온 커밋 초기화
- **WHEN** 추가 페이지를 불러온 상태에서 사용자가 불러온 커밋 초기화를 실행한다
- **THEN** 시스템은 첫 페이지에 담겼던 커밋만 표시한다
- **AND** 저장소를 다시 읽지 않는다
- **AND** 커밋 선택은 그대로 유지한다

#### Scenario: 초기화 뒤 다시 불러오기
- **WHEN** 사용자가 불러온 커밋을 초기화한 뒤 다시 이전 커밋을 더 불러온다
- **THEN** 시스템은 초기화 이전과 같은 다음 페이지를 추가한다

#### Scenario: 되돌릴 커밋이 없음
- **WHEN** 첫 페이지만 불러온 상태다
- **THEN** 시스템은 불러온 커밋 초기화를 제공하지 않는다

#### Scenario: 조회 중 브랜치 이동
- **WHEN** 화면을 연 뒤 작업 브랜치가 다른 커밋을 가리키도록 변경된다
- **THEN** 시스템은 현재 목록이 최신 브랜치 상태와 다름을 표시한다
- **AND** 사용자가 새 이력을 불러오기 전에는 기존 커밋을 새 결과의 입력으로 사용하지 않는다

### Requirement: 합성 선택과 현재 탐색 구분
시스템은 통합 결과에 포함할 커밋의 체크 상태와 현재 자세히 살펴보는 커밋의 탐색 상태를 서로 다른 표시로 유지해야 한다(SHALL). 커밋 행의 카드를 실행하면 그 커밋의 체크 상태가 토글되어야 한다(MUST). 합성할 수 없는 커밋은 카드를 실행해도 체크되지 않아야 한다(MUST NOT). merge commit은 기준 부모를 정하는 흐름과 함께 체크할 수 있어야 한다(SHALL). 선택한 커밋이 있으면 선택을 한 번에 비우는 초기화를 제공해야 한다(MUST).

#### Scenario: 비연속 커밋 선택
- **WHEN** 사용자가 선형 흐름에서 서로 떨어진 합성 가능 커밋의 체크 상자를 선택한다
- **THEN** 시스템은 선택한 모든 커밋의 체크 상태와 선택 개수를 표시한다
- **AND** 사이에 있는 선택하지 않은 커밋은 체크되지 않은 상태로 유지한다

#### Scenario: 카드로 커밋 선택
- **WHEN** 사용자가 체크하지 않은 합성 가능 커밋의 카드를 실행한다
- **THEN** 시스템은 그 커밋을 체크 상태로 표시하고 선택 개수에 포함한다
- **AND** 그 커밋을 현재 살펴보는 커밋으로 표시한다

#### Scenario: 카드로 선택 해제
- **WHEN** 사용자가 이미 체크한 커밋의 카드를 실행한다
- **THEN** 시스템은 그 커밋의 체크를 해제하고 선택 개수에서 제외한다

#### Scenario: 합성할 수 없는 커밋의 카드 실행
- **WHEN** 사용자가 합성할 수 없는 커밋의 카드를 실행한다
- **THEN** 시스템은 그 커밋을 체크하지 않는다
- **AND** 그 커밋을 현재 살펴보는 커밋으로 표시한다

#### Scenario: 체크 상자만 조작
- **WHEN** 사용자가 커밋의 체크 상자만 조작한다
- **THEN** 시스템은 그 커밋의 체크 상태를 변경한다
- **AND** 현재 살펴보는 커밋 표시는 옮겨가지 않는다

#### Scenario: 선택 초기화
- **WHEN** 선택한 커밋이 있는 상태에서 사용자가 선택 초기화를 실행한다
- **THEN** 시스템은 선택 개수를 0으로 표시하고 모든 체크를 해제한다
- **AND** merge commit의 기준 부모 선택도 함께 비운다
- **AND** 불러온 커밋 목록은 줄이지 않는다

#### Scenario: 선택 초기화 뒤 결과 표시
- **WHEN** 계산된 결과가 있는 상태에서 사용자가 선택 초기화를 실행한다
- **THEN** 시스템은 그 결과를 현재 결과로 표시하지 않는다
- **AND** 사용자가 커밋을 다시 선택해 계산할 수 있는 상태를 유지한다

#### Scenario: 비울 선택이 없음
- **WHEN** 선택한 커밋이 없다
- **THEN** 시스템은 선택 초기화를 제공하지 않는다

#### Scenario: 모든 선택 해제
- **WHEN** 사용자가 모든 커밋의 체크를 해제한다
- **THEN** 시스템은 선택 개수를 0으로 표시한다
