## Why

개발자가 여러 커밋 중 검토할 변경만 골랐을 때, 선택하지 않은 변경이 섞이지 않은 최종 파일 상태와 하나의 통합 diff를 신뢰할 수 있게 확인해야 한다. 이 기능은 Prettifer 코어가 제공할 첫 번째 사용자 가치이며 이후 Git 그래프, VS Code 확장과 AI 연동이 공통으로 사용할 기반이 된다.

## What Changes

- 기준 브랜치와 작업 브랜치가 갈라진 지점을 선택과 독립적인 비교 기준으로 사용한다.
- 같은 브랜치 흐름에서 서로 인접하지 않은 커밋을 자유롭게 선택한다.
- 선택한 커밋만 이력 순서대로 반영한 최종 파일 상태와 통합 diff를 생성한다.
- 같은 파일을 여러 선택 커밋이 변경해도 하나의 최종 결과로 합성한다.
- 선택이 바뀌면 이전 계산 결과를 현재 결과로 표시하지 않는다.
- 계산 성공, 실패와 취소 과정에서 사용자의 현재 브랜치와 작업 중인 파일 상태를 보존한다.
- 같은 저장소 상태와 선택에는 일관된 결과를 제공한다.
- 지원할 수 없는 선택이나 합성 실패에는 문제 범위, 원인과 다음 행동을 안내한다.
- 실제 Git 이력을 갖는 검증용 저장소 시나리오로 사용자 동작을 보호한다.

## Capabilities

### New Capabilities

- `composite-diff-generation`: 선형 Git 이력에서 선택한 커밋만 반영된 최종 파일 상태와 통합 diff를 안전하고 일관되게 생성하는 동작

### Modified Capabilities

없음.

## Impact

- Prettifer 코어의 최초 실행 가능한 기능과 자동화 테스트가 추가된다.
- 로컬 Git 저장소를 읽고 선택 결과를 계산하기 위한 Git 실행 환경이 필요하다.
- 이후 Git 그래프와 편집기 연동은 이 변경에서 정의한 선택 결과 생성 동작을 사용한다.
- 공개 API, CLI와 사용자 인터페이스 형식은 이 변경의 범위에 포함하지 않는다.
