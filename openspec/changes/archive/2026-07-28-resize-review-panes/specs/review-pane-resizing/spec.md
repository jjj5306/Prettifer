## ADDED Requirements

### Requirement: 검토 영역 폭 조절 구분자
시스템은 `Changed Files`와 diff 영역 사이에 폭을 조절하는 구분자를 제공해야
한다(MUST). 구분자는 조절할 수 있는 요소임을 시각적으로 알려야 한다(MUST).

#### Scenario: 구분자 표시
- **WHEN** 선택 결과가 준비되어 변경 파일과 diff 영역이 함께 표시된다
- **THEN** 두 영역 사이에 폭 조절 구분자가 표시된다
- **THEN** 구분자에 마우스를 올리면 좌우 조절 상태로 구분된다

#### Scenario: 좁은 화면에서 세로 배치
- **WHEN** 창이 좁아져 변경 파일과 diff 영역이 위아래로 배치된다
- **THEN** 폭 조절 구분자는 표시되지 않는다
- **THEN** 두 영역은 계속 전체 폭으로 표시된다

### Requirement: 마우스로 폭 조절
시스템은 사용자가 구분자를 끌어 `Changed Files`의 폭을 바꿀 수 있게 해야
한다(MUST). 끄는 동안 포인터가 구분자를 벗어나도 조절이 계속되어야 한다(MUST).

#### Scenario: 파일 목록 넓히기
- **WHEN** 사용자가 구분자를 오른쪽으로 끈다
- **THEN** `Changed Files` 영역이 넓어진다
- **THEN** diff 영역이 같은 만큼 좁아진다

#### Scenario: 파일 목록 좁히기
- **WHEN** 사용자가 구분자를 왼쪽으로 끈다
- **THEN** `Changed Files` 영역이 좁아진다
- **THEN** diff 영역이 같은 만큼 넓어진다

#### Scenario: 구분자를 벗어난 이동
- **WHEN** 사용자가 구분자를 누른 채 포인터를 구분자 밖으로 빠르게 이동한다
- **THEN** 폭 조절이 포인터 위치를 계속 따라간다
- **THEN** 포인터를 놓으면 조절이 끝난다

### Requirement: 두 영역의 최소 폭 보장
시스템은 어느 한 영역도 사용할 수 없을 만큼 좁아지지 않도록 조절 범위를
제한해야 한다(MUST).

#### Scenario: 왼쪽 끝까지 끌기
- **WHEN** 사용자가 구분자를 창 왼쪽 끝을 넘어서까지 끈다
- **THEN** `Changed Files`는 최소 폭에서 더 줄어들지 않는다
- **THEN** 파일 상태와 파일 이름을 계속 확인할 수 있다

#### Scenario: 오른쪽 끝까지 끌기
- **WHEN** 사용자가 구분자를 창 오른쪽 끝을 넘어서까지 끈다
- **THEN** diff 영역에 검토할 수 있는 최소 폭이 남는다
- **THEN** `Changed Files`는 그 이상 넓어지지 않는다

### Requirement: 키보드로 폭 조절
시스템은 키보드만으로 구분자에 접근하고 폭을 조절할 수 있게 해야 하며(MUST),
구분자의 현재 폭과 조절 범위를 보조 기술에 제공해야 한다(MUST).

#### Scenario: 방향키 조절
- **WHEN** 사용자가 구분자에 포커스하고 왼쪽 또는 오른쪽 방향키를 누른다
- **THEN** `Changed Files`의 폭이 한 단계씩 줄거나 늘어난다
- **THEN** 보조 기술에 알리는 현재 폭 값이 함께 갱신된다

#### Scenario: 조절 범위 양끝으로 이동
- **WHEN** 사용자가 구분자에 포커스하고 Home 또는 End를 누른다
- **THEN** `Changed Files`가 최소 폭 또는 최대 폭이 된다

#### Scenario: 구분자 포커스 표시
- **WHEN** 사용자가 키보드로 구분자에 포커스한다
- **THEN** 포커스 위치를 시각적으로 확인할 수 있다
- **THEN** 구분자의 이름, 방향과 현재 폭을 보조 기술로 확인할 수 있다

### Requirement: 조절한 폭 유지
시스템은 사용자가 정한 폭을 검토 작업이 이어지는 동안 유지해야 한다(MUST).

#### Scenario: 파일 선택과 보기 전환
- **WHEN** 사용자가 폭을 조절한 뒤 다른 변경 파일을 선택하거나 Tree View와
  List View를 전환한다
- **THEN** 조절한 폭이 그대로 유지된다

#### Scenario: 결과 다시 계산
- **WHEN** 사용자가 폭을 조절한 뒤 선택 결과를 다시 만든다
- **THEN** 조절한 폭이 그대로 유지된다

### Requirement: 기준과 결과 사이 폭 조절
시스템은 diff 안에서 기준 파일과 선택 결과가 차지하는 폭도 사용자가 조절할 수
있게 해야 한다(MUST).

#### Scenario: diff 안쪽 구분자 이동
- **WHEN** 사용자가 기준 파일과 선택 결과 사이의 구분자를 좌우로 끈다
- **THEN** 두 쪽이 차지하는 폭이 함께 바뀐다
- **THEN** 표시 중인 diff 내용과 선택 파일은 바뀌지 않는다
