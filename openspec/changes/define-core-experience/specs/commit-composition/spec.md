## ADDED Requirements

### Requirement: 루트 이력의 비교 기준
시스템은 이전 커밋이 없는 루트 이력을 검토할 때 빈 저장소 상태를 비교
기준으로 사용해야 한다(SHALL).

#### Scenario: 루트 커밋 선택
- **WHEN** 사용자가 이전 커밋이 없는 루트 이력을 통합 결과에 포함한다
- **THEN** 시스템은 파일이 없는 저장소 상태와 루트 커밋의 파일 상태를 비교한다
- **AND** 루트 커밋에서 만들어진 파일을 추가된 파일로 표시한다

### Requirement: 장시간 통합 계산의 진행 범위
시스템은 통합 결과 계산이 1초 안에 끝나지 않으면 현재 처리 범위를 표시하고
사용자가 계산을 취소할 수 있게 해야 한다(SHALL). 취소된 계산의 결과를 완료
결과로 표시하지 않아야 한다(MUST NOT).

#### Scenario: 계산이 1초를 넘음
- **WHEN** 통합 결과 계산이 시작된 뒤 1초 안에 끝나지 않는다
- **THEN** 시스템은 계산 중인 상태와 현재 처리 범위를 표시한다
- **AND** 사용자가 실행할 수 있는 취소 동작을 제공한다

#### Scenario: 장시간 계산 취소
- **WHEN** 사용자가 1초를 넘겨 진행 중인 계산을 취소한다
- **THEN** 시스템은 해당 계산을 중단한다
- **AND** 취소된 계산의 결과를 완료 결과로 표시하지 않는다
