## ADDED Requirements

### Requirement: 파일 경로 기반 그룹화
시스템은 사용자가 정의한 저장소 상대 경로 규칙에 따라 통합 결과의 변경 파일을 그룹으로 구성해야 한다(SHALL). 경로 구분자는 `/`를 사용하고 대소문자를 구분하며, `*`는 경로 한 구간 안의 문자에, `**`는 여러 경로 구간에 일치해야 한다.

#### Scenario: 기능 경로 분류
- **WHEN** 사용자가 `src/auth/**`를 인증 그룹으로 설정하고 해당 경로의 파일이 변경된다
- **THEN** 시스템은 변경 파일을 인증 그룹에 표시한다

### Requirement: 파일 확장자 기반 그룹화
시스템은 사용자가 정의한 파일 확장자 규칙에 따라 변경 파일을 그룹으로 구성해야 한다(SHALL). 확장자 규칙은 `.`으로 시작하고 경로 구분자와 와일드카드를 포함하지 않으며 대소문자를 구분해야 한다.

#### Scenario: 문서와 데이터베이스 분류
- **WHEN** 사용자가 `.md`를 문서 그룹으로, `.sql`을 데이터베이스 그룹으로 설정한다
- **THEN** 시스템은 해당 확장자의 변경 파일을 각 그룹에 표시한다

### Requirement: 계층형 그룹 탐색
시스템은 그룹과 하위 그룹을 계층으로 표현하고 사용자가 펼치거나 접을 수 있게 해야 한다(SHALL).

#### Scenario: 기능 하위 영역 탐색
- **WHEN** 인증 그룹 아래에 로그인 API 하위 그룹이 설정되어 있다
- **THEN** 시스템은 인증, 로그인 API, 변경 파일의 순서로 탐색 가능한 트리를 표시한다

### Requirement: 분류 우선순위
시스템은 하나의 파일이 여러 규칙에 일치할 때 사용자가 예측할 수 있는 순서로 주 그룹을 결정해야 한다(SHALL).

#### Scenario: 여러 규칙에 일치
- **WHEN** 하나의 변경 파일이 경로 규칙과 확장자 규칙에 모두 일치한다
- **THEN** 시스템은 명시된 우선순위가 높은 규칙을 주 그룹으로 결정하고 적용된 규칙을 확인할 수 있게 한다

#### Scenario: 우선순위가 같음
- **WHEN** 하나의 변경 파일이 우선순위가 같은 여러 규칙에 일치한다
- **THEN** 시스템은 설정에 먼저 선언된 규칙을 주 그룹으로 결정한다

### Requirement: 미분류 파일 보존
시스템은 어떤 분류 규칙에도 일치하지 않는 변경 파일을 누락하지 않아야 한다(MUST).

#### Scenario: 일치 규칙 없음
- **WHEN** 변경 파일이 어떤 사용자 규칙에도 일치하지 않는다
- **THEN** 시스템은 해당 파일을 기본 그룹에 표시한다

#### Scenario: 그룹 설정 없음
- **WHEN** 사용자가 그룹 규칙을 설정하지 않았다
- **THEN** 시스템은 모든 변경 파일을 기본 그룹에 표시한다

### Requirement: 잘못된 그룹 규칙 처리
시스템은 잘못된 그룹 규칙이 있어도 유효한 규칙과 변경 파일을 계속 탐색할 수 있게 해야 한다(SHALL).

#### Scenario: 잘못된 경로 패턴
- **WHEN** 그룹 설정에 절대 경로, 상위 경로 이동 또는 지원하지 않는 와일드카드를 포함한 경로 규칙이 있다
- **THEN** 시스템은 해당 규칙의 위치와 원인을 안내하고 나머지 유효한 규칙을 적용한다

#### Scenario: 잘못된 확장자 규칙
- **WHEN** 그룹 설정에 `.`으로 시작하지 않거나 경로 구분자 또는 와일드카드를 포함한 확장자 규칙이 있다
- **THEN** 시스템은 해당 규칙의 위치와 원인을 안내하고 나머지 유효한 규칙을 적용한다

#### Scenario: 설정 변경
- **WHEN** 사용자가 그룹 규칙 또는 우선순위를 변경한다
- **THEN** 시스템은 현재 통합 결과의 파일을 새 설정에 따라 다시 분류한다

### Requirement: 문제 파일 표시
시스템은 통합 과정에서 문제가 발생한 파일도 그룹 탐색에서 찾을 수 있게 해야 한다(SHALL).

#### Scenario: 그룹 안의 문제 파일
- **WHEN** 특정 그룹의 파일에서 통합 문제가 발생한다
- **THEN** 시스템은 해당 파일의 그룹 위치를 유지하고 문제 상태를 함께 표시한다
- **THEN** 시스템은 문제 요약에서 해당 그룹 위치로 이동할 수 있게 한다
