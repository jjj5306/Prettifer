## Why

Git 히스토리에서 원하는 커밋만 골라 검토하려면 커밋별 diff를 반복해서 읽고 머릿속에서 최종 결과를 조합해야 한다. Prettifer는 전체 변경 흐름을 탐색하고 선택한 커밋의 통합 결과를 기능별로 이해할 수 있는 일관된 경험을 제공한다.

## What Changes

- 저장소의 전체 커밋 흐름을 Git 그래프로 탐색한다.
- 그래프에서 서로 인접하지 않은 커밋을 자유롭게 선택한다.
- 선택한 커밋이 모두 반영된 최종 결과를 하나의 좌우 비교 diff로 확인한다.
- 통합 과정의 문제를 가능한 범위에서 처리하고, 남은 문제는 커밋과 파일 단위로 자세히 안내한다.
- 문제가 있는 파일이 있어도 확인 가능한 파일과 결과는 계속 탐색한다.
- 파일 경로와 확장자 규칙으로 변경 파일을 의미 있는 그룹으로 구성한다.
- 커밋을 선택해 해당 커밋의 변경 파일을 보고, 파일을 선택해 접근 가능한 전체 커밋 흐름과 통합 diff를 본다.
- 초기 UX 방향을 README의 목업으로 보존한다.

## Capabilities

### New Capabilities

- `repository-history`: 전체 Git 그래프와 커밋 정보를 탐색하는 동작
- `commit-composition`: 비연속 커밋 선택, 통합 결과 생성, 문제 처리와 상세 안내
- `change-grouping`: 파일 경로와 확장자 규칙을 이용한 변경 그룹 구성
- `file-change-exploration`: 커밋별 변경 파일, 파일별 전체 커밋 흐름, 좌우 통합 diff 탐색

### Modified Capabilities

없음.

## Impact

- Prettifer 코어가 제공해야 하는 초기 제품 동작을 정의한다.
- Git 히스토리, 커밋 선택, 통합 비교, 파일 분류와 탐색 기능이 영향을 받는다.
- VS Code 확장은 이 명세의 탐색 흐름과 상태 표현을 사용한다.
- 구체적인 구현 기술과 외부 배포 형태는 후속 변경에서 결정한다.
