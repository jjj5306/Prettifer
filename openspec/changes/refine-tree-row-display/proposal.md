## Why

실제 저장소(추적 파일 17,807개, 최대 깊이 15)에서 Tree View와 Full Tree를 열면 읽기 어렵다.

행마다 테두리와 둥근 모서리, 버튼 배경이 붙어 트리가 아니라 알약이 쌓인 목록으로 보인다. 행이
자기 내용 너비만 차지해 목록이 들쭉날쭉하고, 레벨당 들여쓰기가 커서 깊이가 조금만 깊어져도 계단이
오른쪽으로 밀린다. 폴더 계층선은 깊은 트리에서 화면을 선으로 채우고, 가로 스크롤바까지 생긴다.

행의 알약 모양은 의도한 표현이 아니다. 앱 전역의 버튼 스타일이 행 클래스보다 명시도가 높아, 행이
지정한 투명 테두리를 이기고 있었다.

Full Tree에는 단일 하위 폴더 경로 합치기가 없다. Tree View에는 있다. 그래서 깊은 경로가 폴더마다
한 행씩 늘어난다.

## What Changes

- 트리 행을 평평하게 만든다. 테두리, 둥근 모서리와 버튼 배경을 없앤다.
- 행이 패널 너비를 채우고, 긴 이름은 패널 경계에서 잘린다.
- 레벨당 들여쓰기를 파일 탐색기 수준으로 줄이고 폴더 계층선을 없앤다.
- 선택과 가리킴을 행 전체를 덮는 띠로 표시한다.
- 행 높이를 줄여 한 화면에 더 많은 경로가 들어오게 한다.
- 트리는 가로로 스크롤하지 않는다.
- Full Tree에도 단일 하위 폴더 경로 합치기를 적용한다.

## Capabilities

### New Capabilities

없음. 두 트리의 표시 방식만 바꾼다.

### Modified Capabilities

- `changed-file-view-toggle`: Tree View의 계층선과 내용 너비 행 요구사항을 없애고, 두 트리에
  공통으로 적용되는 행 표시 요구사항을 둔다. 폴더 접기와 경로 합치기는 유지한다.
- `base-file-tree`: 전체 구조 표시에 단일 하위 폴더 경로 합치기가 더해진다.

## Impact

- `src/desktop/renderer/files/ChangedFilePane.module.css`: 행과 들여쓰기 표시
- `src/desktop/renderer/files/full-tree.ts`: 경로 합치기
- `src/desktop/renderer/files/FullTreeView.tsx`: 합쳐진 행 표시
- 결과 계산, 경로 목록 조회와 파일 선택 동작은 바뀌지 않는다
