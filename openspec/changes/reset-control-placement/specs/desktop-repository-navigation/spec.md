## ADDED Requirements

### Requirement: 커밋 히스토리 초기화 컨트롤 표시
시스템은 커밋 히스토리의 초기화 컨트롤을 패널 제목 줄의 한 동작 묶음에 모아 표시해야
한다(MUST). 각 초기화는 아이콘으로 표시하고, 포인터를 올리면 그 초기화가 되돌리는 대상과 남기는
대상을 설명해야 한다(MUST). 아이콘만 있는 컨트롤은 서로 구별되는 접근성 이름을 가져야
한다(MUST). 목록을 늘리는 컨트롤은 이 묶음에 넣지 않아야 한다(MUST NOT).

#### Scenario: 초기화 두 개가 함께 있음
- **WHEN** 추가 페이지를 불러온 상태에서 선택한 커밋도 있다
- **THEN** 시스템은 두 초기화를 커밋 히스토리 제목 줄의 같은 동작 묶음에 표시한다
- **AND** 이전 커밋을 더 불러오는 컨트롤은 그 묶음 밖에 유지한다

#### Scenario: 초기화가 되돌리는 대상 확인
- **WHEN** 사용자가 초기화 컨트롤에 포인터를 올린다
- **THEN** 시스템은 그 초기화가 되돌리는 대상과 그대로 남는 대상을 설명으로 표시한다

#### Scenario: 아이콘 컨트롤 식별
- **WHEN** 사용자가 아이콘으로만 표시된 초기화 컨트롤을 이름으로 찾는다
- **THEN** 시스템은 각 초기화를 되돌리는 대상이 드러나는 이름으로 구별한다

#### Scenario: 되돌릴 것이 하나만 있음
- **WHEN** 선택한 커밋은 있고 추가로 불러온 커밋은 없다
- **THEN** 시스템은 선택 초기화만 동작 묶음에 표시한다

#### Scenario: 되돌릴 것이 없음
- **WHEN** 선택한 커밋도 추가로 불러온 커밋도 없다
- **THEN** 시스템은 동작 묶음에 초기화를 표시하지 않는다
- **AND** 그 묶음이 제목 줄의 자리를 차지하지 않는다
