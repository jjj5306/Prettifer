## 1. 순수 핵심

- [ ] 1.1 파일 경로에서 심볼 검색 지원 언어를 판별한다
- [ ] 1.2 커서 위치에서 식별자와 그 범위를 추출한다
- [ ] 1.3 언어별 선언 패턴으로 한 줄이 심볼의 선언인지 판정한다
- [ ] 1.4 내용에서 식별자 출현 위치를 찾고 줄 주석과 문자열을 걸러낸다
- [ ] 1.5 각 항목의 경계 조건을 테스트로 고정한다

## 2. 저장소 전역 검색 경계

- [ ] 2.1 비교 기준 커밋을 대상으로 심볼을 검색한다
- [ ] 2.2 검색 결과를 파일, 줄, 내용으로 해석한다
- [ ] 2.3 지원 언어 파일로 검색 대상을 제한한다
- [ ] 2.4 결과 수 상한과 상한 도달 여부를 함께 제공한다
- [ ] 2.5 검색 실패를 내부 명령 노출 없이 진단으로 바꾼다
- [ ] 2.6 작업 트리와 HEAD가 바뀌지 않음을 확인한다

## 3. 경계 계약

- [ ] 3.1 공유 계약에 심볼 검색을 추가한다
- [ ] 3.2 preload가 계약을 노출한다
- [ ] 3.3 main이 기존 신뢰 검사를 거쳐 요청을 처리한다

## 4. 화면

- [ ] 4.1 변경된 파일은 결과 내용으로, 나머지는 기준 검색 결과로 합친다
- [ ] 4.2 정의 이동을 마우스와 키보드로 실행한다
- [ ] 4.3 후보가 여러 개면 목록을 보여주고 선택으로 이동한다
- [ ] 4.4 참조 목록을 표시하고 정의와 참조를 구분한다
- [ ] 4.5 다른 파일로 이동하면 그 파일을 검토 영역에서 연다
- [ ] 4.6 이동 이력을 쌓고 되돌아가기를 제공한다
- [ ] 4.7 정의 없음, 참조 없음, 지원하지 않는 언어, 검색 실패를 표시한다
- [ ] 4.8 목록과 되돌아가기를 키보드만으로 조작할 수 있게 한다

## 5. 언어 표시

- [ ] 5.1 Java와 C/C++ 구문 강조를 추가한다
- [ ] 5.2 파일 확장자를 해당 언어로 연결한다

- [ ] 6.1 lint, typecheck와 전체 유닛 테스트를 실행한다
- [ ] 6.2 실제 앱에서 정의 이동, 참조 목록과 되돌아가기를 검증한다
- [ ] 6.3 검토 전후 저장소 상태가 같은지 확인한다
- [ ] 6.4 e2e와 릴리스 산출물 생성을 실행한다
- [ ] 6.5 메인 스펙에 반영하고 OpenSpec strict 검증을 실행한다
