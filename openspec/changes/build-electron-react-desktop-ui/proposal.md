## Why

Prettifer 코어는 선택한 커밋의 통합 결과를 계산할 수 있지만 사용자가 직접 조작할 화면이 없어 코드 예제를 작성해야만 사용할 수 있다. 현재 지원 범위를 정확히 안내하는 데스크톱 UI를 제공해 로컬 저장소 선택부터 통합 diff 검토까지의 첫 실행 경험을 완성한다.

## What Changes

- Windows에서 실행할 수 있는 Electron + React 데스크톱 앱을 추가한다.
- 사용자가 로컬 Git 저장소와 비교 기준·작업 브랜치를 선택하고, 현재 지원되는 선형 이력의 커밋을 탐색하게 한다.
- 통합 결과에 포함할 커밋 선택과 현재 살펴보는 커밋을 구분해 표시한다.
- 선택한 커밋의 통합 결과 생성, 진행 상태, 취소, 오류 안내와 재시도를 화면에서 제공한다.
- 통합 결과의 변경 파일을 탐색하고 기준 파일과 최종 파일을 좌우 diff로 제공한다.
- 실제 비교 기준, 적용 순서, 선택 범위와 작업 트리 보존 상태를 결과와 함께 표시한다.
- 저장소 열기부터 파일 diff 확인까지 키보드로 조작할 수 있고 현재 포커스와 선택 상태가 구분되는 화면을 제공한다.
- 개발 앱과 Windows 패키지를 재현 가능한 명령으로 만들고 실행 상태를 자동 검증한다.
- 상세 튜토리얼과 사용 매뉴얼을 문서화 이슈 #5의 후속 범위로 연결한다.

## Capabilities

### New Capabilities

- `desktop-repository-navigation`: 데스크톱 앱 실행, 로컬 저장소 열기, 비교 범위 선택, 선형 커밋 탐색과 합성 대상 선택 동작
- `desktop-composite-diff-review`: 선택 커밋의 통합 결과 생성·취소, 결과 정보, 변경 파일 목록, 좌우 diff와 오류 복구 동작

### Modified Capabilities

없음.

## Impact

- 기존 TypeScript 코어를 사용하는 데스크톱 실행 진입점과 사용자 화면이 추가된다.
- Electron, React, Monaco Editor, 데스크톱 패키징과 화면 자동화 테스트 의존성이 추가된다.
- 저장소 이력과 브랜치 정보를 화면에 제공하기 위한 읽기 전용 Git 조회 기능이 필요하다.
- 기존 통합 diff 계산 계약과 작업 트리 보존 계약은 유지된다.
- React 코드 규칙, Electron 프로세스 보안 경계, 접근성 및 화면 테스트가 필수 품질 기준에 포함된다.
- GitHub 이슈 #7과 문서화 이슈 #5가 이 변경의 구현 및 후속 문서 범위를 추적한다.
