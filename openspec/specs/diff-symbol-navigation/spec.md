# diff-symbol-navigation Specification

## Purpose
검토 화면에서 심볼의 정의와 참조로 이동하고 돌아온다. 저장소 전체를 대상으로 하되
변경된 파일은 선택 결과의 내용을 기준으로 하며, 사용자의 작업 트리는 건드리지 않는다.

## Requirements

### Requirement: 심볼 정의로 이동
시스템은 검토 중인 파일의 심볼에서 그 심볼의 정의 위치로 이동할 수 있게 해야 한다(SHALL). 이동은 마우스와 키보드 모두로 시작할 수 있어야 한다(MUST). 이동 후 커서는 선언 줄에서 그 심볼이 있는 위치에 놓여야 하고(MUST), 도착한 줄은 화면에서 구분되어야 한다(MUST). 후보가 여러 종류로 발견되면 사용자가 심볼을 지목한 자리의 맥락에 가장 맞는 종류를 우선해야 한다(MUST).

#### Scenario: 같은 파일의 정의로 이동
- **WHEN** 사용자가 검토 중인 파일에서 같은 파일에 정의된 심볼의 이동을 실행한다
- **THEN** 시스템은 정의가 있는 줄로 검토 위치를 옮긴다
- **AND** 검토 중인 파일은 그대로 유지된다

#### Scenario: 다른 파일의 정의로 이동
- **WHEN** 사용자가 다른 파일에 정의된 심볼의 이동을 실행한다
- **THEN** 시스템은 그 파일을 검토 영역에서 열고 정의가 있는 줄로 옮긴다

#### Scenario: 멤버 선언 위치로 이동
- **WHEN** 사용자가 어떤 형의 멤버로 선언된 심볼의 이동을 실행한다
- **THEN** 시스템은 그 멤버가 선언된 줄로 옮기고 커서를 그 줄의 심볼 위치에 둔다
- **AND** 도착한 줄을 화면에서 구분해 표시한다

#### Scenario: 객체 생성 자리에서 이동
- **WHEN** 사용자가 객체를 만드는 자리의 형 이름에서 이동을 실행한다
- **THEN** 시스템은 그 이름의 생성자 선언을 우선한다
- **AND** 생성자 선언이 하나면 그 위치로 바로 이동한다
- **AND** 생성자 선언이 없으면 형 선언으로 이동한다

#### Scenario: 그 밖의 자리에서 이동
- **WHEN** 사용자가 객체를 만드는 자리가 아닌 곳의 형 이름에서 이동을 실행한다
- **THEN** 시스템은 형 선언을 우선하고 생성자 선언으로 보내지 않는다

#### Scenario: 정의 후보가 여러 개
- **WHEN** 우선하는 종류의 정의 후보가 여러 개 발견된다
- **THEN** 시스템은 그 후보 목록을 파일, 줄과 선언 종류와 함께 표시한다
- **AND** 사용자가 고른 후보로 이동한다

#### Scenario: 정의를 찾지 못함
- **WHEN** 심볼의 정의를 찾지 못한다
- **THEN** 시스템은 찾지 못했음과 대상 심볼을 표시한다
- **AND** 참조 목록을 확인하는 행동을 안내한다

### Requirement: 심볼 참조 목록
시스템은 심볼의 참조와 호출부 목록을 표시하고 항목을 선택해 이동할 수 있게 해야 한다(SHALL). 목록은 각 항목이 선언인지, 어떤 종류의 선언인지를 구분해 표시해야 한다(MUST).

#### Scenario: 참조 목록 확인
- **WHEN** 사용자가 심볼의 참조 목록을 요청한다
- **THEN** 시스템은 각 참조의 파일 경로, 줄 번호와 해당 줄 내용을 표시한다
- **AND** 선언으로 인식된 위치를 그 선언 종류와 함께 참조와 구분해 표시한다
- **AND** 종류로 걸러내지 않고 찾은 모든 위치를 표시한다

#### Scenario: 참조 항목으로 이동
- **WHEN** 사용자가 참조 목록에서 항목을 선택한다
- **THEN** 시스템은 그 파일을 열고 해당 줄로 검토 위치를 옮긴다
- **AND** 커서를 그 줄의 심볼 위치에 두고 도착한 줄을 구분해 표시한다

#### Scenario: 참조가 없음
- **WHEN** 심볼의 참조를 찾지 못한다
- **THEN** 시스템은 참조가 없음과 대상 심볼을 표시한다

### Requirement: 이동 이력과 되돌아가기
시스템은 심볼 이동으로 검토 위치가 바뀐 뒤 이전 위치로 돌아갈 수 있게 해야 한다(SHALL).

#### Scenario: 이동 뒤 되돌아가기
- **WHEN** 사용자가 심볼 이동으로 다른 위치로 옮긴 뒤 되돌아가기를 실행한다
- **THEN** 시스템은 이동 직전에 보던 파일과 줄로 돌아간다

#### Scenario: 여러 번 이동한 뒤 되돌아가기
- **WHEN** 사용자가 심볼 이동을 여러 번 수행한 뒤 되돌아가기를 반복한다
- **THEN** 시스템은 이동한 역순으로 이전 위치를 되짚는다

#### Scenario: 돌아갈 위치가 없음
- **WHEN** 이동 이력이 없는 상태에서 사용자가 되돌아가기를 실행한다
- **THEN** 시스템은 검토 위치를 바꾸지 않는다

### Requirement: 검색 대상과 저장소 보호
시스템은 심볼을 저장소 전체에서 찾아야 한다(SHALL). 변경된 파일은 선택 결과의 내용을 기준으로 하고 나머지 파일은 비교 기준 상태를 기준으로 해야 한다(MUST). 검색은 사용자의 branch, HEAD와 작업 트리를 변경하지 않아야 한다(MUST NOT).

#### Scenario: 변경되지 않은 파일의 정의
- **WHEN** 심볼의 정의가 선택 결과에 포함되지 않은 파일에 있다
- **THEN** 시스템은 비교 기준 상태의 그 파일에서 정의를 찾아 제공한다

#### Scenario: 변경된 파일의 심볼
- **WHEN** 심볼이 선택 결과에서 변경된 파일에 있다
- **THEN** 시스템은 비교 기준 내용이 아니라 선택 결과의 내용을 기준으로 위치를 제공한다

#### Scenario: 검색 뒤 저장소 상태
- **WHEN** 사용자가 심볼 이동과 참조 검색을 여러 번 수행한다
- **THEN** 저장소의 branch, HEAD와 staged/unstaged/untracked 상태가 검색 전과 같다

#### Scenario: 결과 수 상한
- **WHEN** 심볼이 표시 상한보다 많이 발견된다
- **THEN** 시스템은 상한까지의 항목을 표시하고 목록이 잘렸음을 알린다

### Requirement: 선택 결과 밖 파일 열기
시스템은 선택 결과에 포함되지 않은 파일로 이동할 때 그 파일을 비교 기준 상태로 열고, 선택 결과가 아님을 표시해야 한다(MUST). 이 파일을 읽을 수 없는 경우 이유와 다음 행동을 표시해야 한다(MUST).

#### Scenario: 선택 결과 밖 파일 표시
- **WHEN** 사용자가 선택 결과에 없는 파일의 위치로 이동한다
- **THEN** 시스템은 그 파일의 비교 기준 내용을 읽기 전용으로 표시한다
- **AND** 비교 대상이 없으므로 diff가 아니라 하나의 문서로 표시한다
- **AND** 그 파일이 선택 결과에 포함되지 않았음을 표시한다

#### Scenario: 열 수 없는 파일
- **WHEN** 이동 대상 파일이 비교 기준에 없거나, 바이너리이거나, 검토할 수 없을 만큼 크다
- **THEN** 시스템은 열 수 없는 이유와 다음 행동을 표시한다
- **AND** 내부 명령과 저장소 경로를 노출하지 않는다

#### Scenario: 선택 결과 밖 파일에서 되돌아가기
- **WHEN** 사용자가 선택 결과 밖 파일로 이동한 뒤 되돌아가기를 실행한다
- **THEN** 시스템은 이동 직전에 검토하던 선택 결과의 파일과 줄로 돌아간다

### Requirement: 지원하지 않는 언어와 검색 실패 안내
시스템은 심볼 검색을 지원하지 않는 파일과 검색이 실패한 경우를 구분해 알려야 한다(MUST).

#### Scenario: 지원하지 않는 언어
- **WHEN** 사용자가 심볼 검색을 지원하지 않는 파일에서 이동을 실행한다
- **THEN** 시스템은 그 파일 형식에서는 심볼 이동을 제공하지 않음을 표시한다

#### Scenario: 검색 실패
- **WHEN** 저장소 검색이 실패한다
- **THEN** 시스템은 검색을 완료할 수 없음과 다시 시도하는 행동을 표시한다
- **AND** 내부 명령과 경로를 노출하지 않는다

### Requirement: 키보드만으로 심볼 탐색
시스템은 정의 이동, 참조 목록 탐색과 되돌아가기를 키보드만으로 수행할 수 있게 해야 한다(MUST).

#### Scenario: 키보드로 정의 이동
- **WHEN** 사용자가 심볼에 커서를 두고 정의 이동 키를 누른다
- **THEN** 시스템은 마우스 조작과 같은 결과로 이동한다

#### Scenario: 키보드로 후보와 참조 목록 탐색
- **WHEN** 후보 목록 또는 참조 목록이 표시된다
- **THEN** 사용자는 키보드로 항목 사이를 이동하고 선택할 수 있다
- **AND** 목록의 현재 위치를 확인할 수 있다

### Requirement: 이동 가능한 심볼 표시
시스템은 이동을 시작하는 조합키를 누른 동안 커서 아래의 식별자를 이동 가능한 대상으로 표시해야 한다(MUST). 표시는 실제로 이동할 대상과 같은 범위여야 한다(MUST).

#### Scenario: 조합키를 누른 채 식별자 위에 둔다
- **WHEN** 사용자가 이동 조합키를 누른 채 식별자 위에 포인터를 둔다
- **THEN** 시스템은 그 식별자를 이동 가능한 대상으로 표시한다
- **AND** 표시 범위는 그 자리를 눌렀을 때 이동할 심볼의 범위와 같다

#### Scenario: 조합키를 떼거나 식별자를 벗어난다
- **WHEN** 사용자가 조합키를 떼거나 포인터를 식별자 밖으로 옮긴다
- **THEN** 시스템은 이동 가능 표시를 지운다

#### Scenario: 조합키 없이 식별자 위에 둔다
- **WHEN** 사용자가 조합키를 누르지 않고 식별자 위에 포인터를 둔다
- **THEN** 시스템은 이동 가능 표시를 하지 않는다

### Requirement: 선언 종류 판정
시스템은 한 줄이 심볼을 선언하는지 판정할 때 선언의 종류를 함께 판정해야 한다(MUST). 종류는 형, 생성자, 메서드, 필드, 지역 변수, 별칭, 매크로를 구분해야 한다(MUST). 선언이 아닌 줄은 어떤 종류로도 판정하지 않아야 한다(MUST NOT).

#### Scenario: 형 선언과 생성자 구분
- **WHEN** 어떤 줄이 형을 선언하고 다른 줄이 같은 이름의 생성자를 선언한다
- **THEN** 시스템은 두 줄을 서로 다른 종류로 판정한다

#### Scenario: 선언과 사용 구분
- **WHEN** 어떤 줄이 심볼을 호출하거나 대입하거나 반환한다
- **THEN** 시스템은 그 줄을 선언으로 판정하지 않는다

#### Scenario: 애너테이션이 앞에 오는 선언
- **WHEN** 선언 줄 앞에 애너테이션이 함께 적혀 있다
- **THEN** 시스템은 애너테이션이 없는 같은 선언과 같게 판정한다

#### Scenario: 수정자가 없는 선언
- **WHEN** 접근 수정자 없이 형과 이름만으로 멤버나 지역 변수를 선언한다
- **THEN** 시스템은 그 줄을 선언으로 판정한다
